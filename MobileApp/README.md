# Shared application

Expo and React Native render the Refined 2 screens on Android, iPhone, and the installable website. Routes are defined in [App.js](App.js). Shared screen code lives in [refined](refined). Device adapters handle platform capabilities and session storage.

Use [Development](../docs/DEVELOPMENT.md) for local setup and [Deployment](../docs/DEPLOYMENT.md) for packaging. The [user guide](../docs/USER_GUIDE.md) lists the journeys to check. Use [the frontend API handoff](../backend/FRONTEND_HANDOFF.md) when changing an app request.
