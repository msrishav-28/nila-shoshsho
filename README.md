# Nila Shoshsho

Nila Shoshsho helps farmers manage plots, check weather and market information, ask crop questions, and arrange transport. Staff can review accounts and documents through restricted controls. The website and native builds share the Refined 2 interface.

## Try the web beta

Open the [Nila Shoshsho web beta](https://nila-shoshsho-pwa.vercel.app/) and select **Create account** or **Log in**. The public account forms and signed-out protections have been checked. The full two-account test used the isolated test database. Android has an emulator build. iPhone signing and device testing are pending.
