# Backend contract

[openapi.json](openapi.json) describes HTTP methods, inputs and responses. [api-contract.json](api-contract.json) inventories the account and advice routes. The running handlers and passing contract tests establish behavior.

Use [frontend handoff](FRONTEND_HANDOFF.md) for app integration and [configuration](CONFIGURATION.md) for providers. Historical proposals live in Git history and are summarized in the [roadmap](ROADMAP.md).
