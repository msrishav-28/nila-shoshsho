# Implementation status

The shared Refined 2 app, account service and advice service are present. Account records, plots, private uploads, staff review, transport, notifications and the advice tools have implemented handlers. Each hosted feature still needs a supported configuration and a release check.

The [release checklist](RELEASE.md) records executed evidence and open gates. The [roadmap](ROADMAP.md) records proposed integrations. Source code and tested provider responses establish behavior.
